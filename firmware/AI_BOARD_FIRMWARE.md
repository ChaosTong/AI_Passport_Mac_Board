# AI Board firmware (vendored ai-passport)

This tree is the **AI Board–customized** FoloToy AI Passport firmware (MESSAGES page, UI tweaks, etc.).

Build/flash via:

```bash
./scripts/build-firmware.sh
./scripts/build-firmware.sh flash
```

Upstream checkout lives at `../ai-passport` (or `~/Developer/ai-passport`) and should stay stock unless you intentionally patch it.
