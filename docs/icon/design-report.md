# MacBoard icon — design report

## Brief

`pocket display + Mac-to-board bridge + clever alertness`

## Three directions

| Direction | Metaphor | Lane | Hook | Palette | 32 px | Score |
| --- | --- | --- | --- | --- | --- | ---: |
| **Link Tile** (selected) | Rounded companion display + BLE bead | Soft 3D object-character | Three yellow progress bars + sky link dot | Violet Tech | White squircle, pupils, bars, dot | 47/50 |
| Wave Puck | Music waveform on a round puck | Gradient silhouette | Single thick wave contour | Coral Friendly | Wave + two dots | 42/50 |
| Build Capsule | Hammer-free compile capsule with status LED | Minimal dimensional glyph | Glowing top LED only | Blue Trust | Capsule + LED | 41/50 |

**Link Tile** wins: reads as both hardware face and build log; matches MacBoard (music + Xcode on a linked board).
